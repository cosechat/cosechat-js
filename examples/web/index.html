Identity

Keys (keyset and recent ratchets) are kept in this browser's IndexedDB. Lock… encrypts them with a passphrase (scrypt + AES-GCM, the same format as the Node and Python storage examples). Export writes the plain keyset: keep that file safe.

Connection

LoRa: RNode over Web Serial

Use a frequency your region allows. With both roads, this page links LoRa and the relay only for itself; run a transport node to bridge them for others.

Find someone

    Contact card

    A signed full announce. Anyone who adds it can message you once the mesh has a path.

    Ratchet

    Messages are sealed to your announced ratchet. Rotating it gives forward secrecy: in this page old ratchets live in memory only.

    Propagation

    Propagation nodes hold sealed messages for peers that are offline.
